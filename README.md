# Amanos — ReqRes Flutter demo

تطبيق Flutter لعرض مستخدمي ReqRes دون الحاجة إلى تشغيل Flask.

## التشغيل

1. ثبّت Flutter المتوافق مع Dart 3.11.4 أو أحدث.
2. احصل على مفتاح API من https://app.reqres.in/ وفق توثيق https://reqres.in/docs.
3. شغّل:

```powershell
flutter pub get
flutter run -d windows --dart-define=REQRES_API_KEY=YOUR_API_KEY
```

يمرر التطبيق المفتاح في ترويسة `x-api-key`. عنوان API هو
`https://reqres.in/api`، بينما `app.reqres.in` هو لوحة إدارة الخدمة.

حساب تجربة تسجيل الدخول: `eve.holt@reqres.in` وكلمة المرور `cityslicka`.
يوجد زر لتعبئة بيانات التجربة في شاشة الدخول. يعتمد قبول الحساب على
خدمة ReqRes؛ التطبيق لا ينشئ حسابات محلية ولا يتجاوز أخطاء تسجيل الدخول.

لإنشاء APK للمشرف:

```powershell
flutter build apk --release --dart-define=REQRES_API_KEY=YOUR_API_KEY
```

الناتج: `build/app/outputs/flutter-apk/app-release.apk`.
المشرف يحتاج تثبيت التطبيق فقط، واتصال إنترنت عند أول تسجيل دخول وتحميل.

## ما تم تنفيذه

- تسجيل دخول عبر `POST /login` وإلغاء مسار MFA القديم.
- حفظ الرمز في Flutter Secure Storage واستعادة الجلسة عند إعادة الفتح.
- قائمة مستخدمين عبر `GET /users?page=1&per_page=6` مع إجمالي المستخدمين.
- تنقل بين الصفحات، تحديث بالسحب أو الزر، وتفاصيل المستخدم.
- حفظ كل صفحة وبيانات pagination في Hive بعد تحميلها بنجاح.
- الرجوع إلى الصفحة المحفوظة عند فشل الاتصال، مع رسالة توضح مصدر البيانات.
- الاحتفاظ بالصفحة الحالية عند فشل تحميل صفحة أخرى وإتاحة إعادة المحاولة.
- تسجيل خروج يمسح جلسة الدخول؛ لا تُخزّن كلمة المرور.

## تجربة وضع عدم الاتصال

1. سجّل الدخول أثناء توفر الإنترنت.
2. حمّل الصفحة الأولى ثم انتقل إلى الصفحة الثانية لحفظهما.
3. اقطع الاتصال بالإنترنت ثم حدّث القائمة وتنقل بين الصفحتين.
4. أغلق التطبيق وافتحه؛ تستعاد الجلسة وتعرض الصفحة الأولى من Hive.
5. الصفحة التي لم تُحمّل سابقًا لا يمكن عرضها دون اتصال، وتظهر رسالة بذلك.
6. بعد عودة الإنترنت اضغط تحديث لجلب البيانات الحديثة.

تُحفظ بيانات المستخدمين ومعلومات الصفحات في Hive. صور المستخدمين تأتي
من روابط خارجية، وتظهر أيقونة بديلة عندما يتعذر تحميل الصورة دون إنترنت.
أخطاء الخدمة مثل 401 و403 و429 لا تعامل كنجاح من الذاكرة المحلية.
تسجيل دخول جديد بعد تسجيل الخروج يحتاج الإنترنت. هذه جلسة تطبيق تجريبي،
والرمز المحفوظ ليس إثباتًا لصلاحية جلسة على خادم مخصص.

## البنية

`core`: الشبكة، التخزين الآمن، الثيم، حقن الاعتماديات، وإعدادات اللغة.

`features/auth` و`features/users`: طبقات data / domain / presentation،
مع Repository وUseCase وCubit. تخزين Hive يعتمد على JSON دون توليد adapters.

## حقن الاعتماديات باستخدام get_it

تُسجّل الاعتماديات في `lib/core/di/service_locator.dart` عبر `setupDependencies()`.
يقتصر `main.dart` على تهيئة Flutter وHive ثم حقن الاعتماديات وتشغيل `AmanosApp`.
توجد شجرة التطبيق ومزوّدات Cubit في `lib/app.dart`.

- `registerSingleton`: صناديق Hive المفتوحة مسبقًا بعد انتظار تهيئتها، بأسماء مستقلة.
- `registerLazySingleton`: DioClient وDio وSecureStorage وخدمة إعدادات اللغة، ومصادر البيانات،
  وrepositories المسجّلة عبر واجهات domain، وuse cases. تُنشأ عند أول استخدام وتُشارك بعدها.
- `registerFactory`: LoginCubit وUsersCubit وLocaleCubit، بحيث يدير BlocProvider عمر كل نسخة ويغلقها.
  يعيش LocaleCubit وLoginCubit على مستوى التطبيق، وUsersCubit طوال جلسة المستخدم.

يبقى حقن الاعتماديات في نقطة التجميع؛ الواجهات تعتمد على Cubits وdomain ولا تستورد طبقة data.
يُغلق Dio وصناديق Hive عند إعادة ضبط service locator في الاختبارات.

## العربية والإنجليزية

يستخدم التطبيق نظام Flutter الرسمي: `flutter_localizations` و`intl` و`gen-l10n`.
مصادر النصوص هي `lib/l10n/app_ar.arb` و`lib/l10n/app_en.arb`، وإعداد التوليد في `l10n.yaml`.
توجد الملفات المولّدة في `lib/l10n/generated/`؛ عدّل ARB ثم شغّل:

```powershell
flutter gen-l10n
```

العربية هي اللغة الافتراضية. لتغيير اللغة اضغط أيقونة الكرة الأرضية في AppBar،
سواء في شاشة تسجيل الدخول أو المستخدمين، ثم اختر «العربية» أو «English».
يضبط Flutter الاتجاه تلقائيًا: العربية RTL والإنجليزية LTR، مع إبقاء عناوين البريد LTR.
لا يؤدي تغيير اللغة إلى إعادة تسجيل الدخول أو إعادة تحميل الصفحة الحالية.

تُحفظ اللغة محليًا عبر `LocaleCubit` و`LocaleStorage` في صندوق Hive منفصل باسم
`app_settings` بالمفتاح `locale`، وتُقرأ قبل بناء الواجهة. يبقى كاش المستخدمين في
`reqres_users` ولا تختلط به إعدادات اللغة. يستمر اختيار اللغة بعد الإغلاق أو تسجيل الخروج.
عند تعذر الحفظ يبقى الاختيار الحالي وتظهر رسالة مترجمة.

تُمرر الأخطاء كرموز مستقلة عن اللغة، وتُترجم في presentation عند العرض، لذلك تتغير
رسائل الخطأ الحالية فور تبديل اللغة. تفاصيل أخطاء الخادم محفوظة للتشخيص، بينما تعرض
الأخطاء غير المعروفة رسالة عامة مترجمة.

## التحقق

```powershell
dart format lib
flutter analyze
flutter test
```

تغطي الاختبارات الأصلية الجلسة وReqRes وpagination وكاش Hive وأخطاء الاتصال والخادم.
تضيف `test/di_localization_test.dart` اختبارات لتسجيل الاعتماديات، وعزل صندوق الإعدادات،
واستعادة اللغة بعد إعادة فتح Hive، وفشل حفظها، وترجمة الأخطاء، ومسارات الواجهة باللغتين:
الدخول، التبديل، الاتجاه، التفاصيل، التنقل، التحديث دون اتصال، استعادة الجلسة والخروج.
طلبات HTTP في الاختبارات محاكاة ولا تحتاج مفتاح API حقيقيًا.

للتحقق اليدوي مع ReqRes: شغّل أمر Windows أعلاه بمفتاحك، وجرّب الدخول وتغيير اللغة
وإعادة فتح التطبيق، ثم حمّل الصفحتين واقطع الإنترنت وجرّب التحديث والتنقل والتفاصيل.
أعد اختيار العربية للتأكد من رجوع RTL، ثم سجّل الخروج وتحقق أن اللغة بقيت محفوظة.
لا تضع مفتاح API داخل الكود أو README أو الملفات المرفوعة إلى GitHub.
